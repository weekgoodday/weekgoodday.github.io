LagMemo: Language-aware 3DGS Memory for Multi-modal Navigation

Leveraging 3D Gaussian Splatting for effective open-vocabulary, multi-goal navigation tasks.

Read Paper View Code Watch Video

About LagMemo

LagMemo is a novel approach for visual navigation, integrating language-aware 3D Gaussian Splatting to handle multi-modal and open-vocabulary tasks in real-world environments.

Method Overview

Step 1: Memory Construction

Construct a 3D memory of the environment using Gaussian splatting techniques.

Step 2: Goal Localization

Use language-based queries to locate goals within the environment.

Step 3: Multi-goal Navigation

Navigate to multiple goals, incorporating language and spatial information.

Results

LagMemo outperforms state-of-the-art methods on multi-modal, multi-goal navigation tasks. Here are the key metrics:

  • Success Rate (SR): 85%
  • Success-weighted Path Length (SPL): 72%
